# adandra Places of Belonging — concept website

A dependency-free, multi-page concept website. It uses plain HTML, CSS and JavaScript so there is no React/Vite dependency that can blank the page.

## Run

1. Make sure Node.js is installed.
2. Open this folder in VS Code.
3. Run `npm run dev` in the terminal.
4. Open `http://localhost:3000`.

No `npm install` is required because the server uses only Node.js built-in modules.

## Pages
- Home — index.html
- Explore — explore.html
- Communities — communities.html
- For Organisations — organisations.html
- About — about.html
- Contact — contact.html
- Place detail — place.html?id=corner-space

## Working interactions
- Mobile navigation
- Explore search and filters
- Save place state using localStorage
- Community join/leave using localStorage
- Organisation dashboard tabs
- Place check-in state using localStorage
- Directions open in Google Maps
- Contact form opens the visitor's email app; nothing is silently submitted
